# Маршрутизация дизайна

Единственный источник правил маршрутизации — [design-router/SKILL.md](skills/design-router/SKILL.md).

Агент читает `design-core` один раз и добавляет только нужные специализации. Для большого продукта публичные и рабочие страницы маршрутизируются отдельно. Общая бренд-система сохраняется.

Автовыбор выполняет coding-agent по описаниям Skills; это не отдельная программа-классификатор. Для более явного входа используйте `$design-router` в Codex или `/design-router` в Claude Code и Cursor. Способы установки и усиления автоматического входа описаны в [README](README.md).
