# Изменения

База форка: `456d9e0d3e2d84c748bb143c6ca3d90c45e16213`.
Рабочая ветка: `feat/universal-ai-designer`.

## Исходное состояние

В репозитории были `landing-page-design`, `figma-designer`, README, MIT-лицензия Elaya, баннер, Python-валидатор и его тесты/CI. Landing Skill применялся ко всему web UI и смешивал конверсионную стратегию с фиксированными эстетическими правилами. Figma Skill — отдельный подробный workflow со своими инструментальными зависимостями.

## Новая структура и границы

Добавлены `design-router`, `design-core` и шесть специалистов для приложений, аналитики, администрирования, форм, таблиц и мониторинга. Вместе с адаптированным лендингом это восемь дизайн-модулей и роутер. Core содержит общие требования, специалисты — конкретные решения, роутер — выбор и композицию. Новые SKILL.md написаны на английском для переносимости, пользовательская документация и задания — на русском.

## Инструменты и проверка

Добавлен установщик для трёх агентов с предохранением от перезаписи, переносом полного набора и опциональным правилом автоматического входа. Добавлены тесты установки и валидатор локальных ссылок, расширен существующий CI. Исходный валидатор и его тесты сохранены.

Добавлены два задания для реальной UI-проверки, fixture запусков, матрица маршрутизации, негативные сценарии и критерии качества. Выполненные проверки и оставшиеся ограничения отражаются отдельно в `VALIDATION.md`.
