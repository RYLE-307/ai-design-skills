## Что доказывают тесты установки

Проверены полная побайтовая копия всех файлов веб-набора для трёх агентов, разрешение ссылок уже в установленной копии, общий каталог Codex/Cursor, повторный запуск без изменений, сохранение существующего AGENTS.md, отказ от конфликтующего файла до остальных записей, отсутствие routing-правил без флага, отказ для неполного источника/отсутствующего проекта, сохранение изменённого пользователем routing-блока и отказ от перенаправленного через symlink каталога. Проверено обнаружение отсутствующей зависимости после повреждения установленной копии.

Тесты исходного валидатора сохранены. CI дополнен проверкой переносимости ссылок; локальный успешный запуск не означает уже выполненный GitHub Actions run.

## Проверка содержания

Просмотрены границы модулей и зависимости: core не вызывает специалистов; специалисты не вызывают router; единственная таблица маршрутизации находится в router. Требования к основным состояниям и общий quality rubric находятся в core. Доменные проверки уточняют их для конкретных операций.

Для лендинга сохранены стратегия, варианты структуры, смысловая работа с текстом и доказательствами, а фиксированные визуальные ограничения переведены в необязательное направление. Исходный Figma workflow не входит в автоматическую веб-установку. Оригинальные авторские уведомления сохранены.
