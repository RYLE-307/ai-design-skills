# Два проверенных UI-примера

Результаты сопровождаемого прогона заданий ShiftNest и RelayOps, 3–4 ноября 2026 года. Это воспроизводимые локальные демо, а не универсальные шаблоны для всех следующих проектов и не доказательство автоматического выбора Skills.

Из корня репозитория:

```bash
python -m http.server 8765 --bind 127.0.0.1 --directory examples/ui
```

- ShiftNest: `http://127.0.0.1:8765/shiftnest/`
- RelayOps: `http://127.0.0.1:8765/relayops/`
- Увеличение текста: `http://127.0.0.1:8765/qa.html`
- Прямая ссылка: `http://127.0.0.1:8765/relayops/?q=run-1042&run=run-1042`

Достаточно Python 3 и браузера; сборка и npm-зависимости не нужны. Формы и повторы используют таймеры в памяти. Нет внешних шрифтов, аналитики, API-запросов или сохранения данных формы. Перезагрузка сбрасывает mock-данные.

В форме ShiftNest раскройте «Проверка демо-ответа». В RelayOps раскройте «Локальный mock · инструменты проверки»: доступны медленный ответ, отказ, частичный отказ, read-only, пустой workspace, ошибка загрузки, восстановление и удаление записи для проверки пагинации. `fixture.js` — JS-обёртка исходного `examples/fixtures/workflow-runs.json`; она позволяет запускать пример и без fetch. При изменении исходных данных обновляйте обёртку вместе с ними.

`qa.html` меняет корневой размер шрифта с 16 до 32 px внутри того же интерфейса. Это проверка относительных размеров текста через harness, не эмуляция системной настройки или browser zoom. Для полного прогона также используйте обычные настройки своего браузера.

Повторите [задание лендинга](../saas-landing.md) и [задание рабочего экрана](../saas-workspace.md). Дополнительно: откройте прямую ссылку в новой вкладке, перезагрузите её, затем нажмите «К списку»; переключите read-only во время медленного массового повтора; проверьте Tab/Shift+Tab в деталях.

[qa-results.json](qa-results.json) — журнал реально выполненных браузерных действий и наблюдений, не исполняемый тестовый раннер. Записи `baseline` и `landing.text200-fixed-320` сохраняют обнаруженные ошибки до окончательных исправлений. Для цикла фокуса итоговые успешные проверки имеют суффикс `*-final`; ранние попытки тоже сохранены. Проверка отсутствия браузерных ошибок не засчитана: подробности и остальные ограничения в [отчёте](../../docs/UI_VALIDATION.md). CI проверяет Skills, а не повторяет эти UI-действия.
